# ingredients-predictor
Project made for Advanced Artificial Neural Networks at University of Warsaw

## App setup
1. Create a Python environment. Install packages from ```requirements.txt``` file
2. Download ```cc.en.300.bin.gz``` file from https://www.kaggle.com/datasets/sanyatargrenkin/cc-en-300-bin and unpack it in the directory
3. Make sure that ```app.py```, ```recipe_fasttext_mlp.pt``` and  ```recipe_fasttext_labels.json``` are present in the directory
4. Run the app using ```python app.py```
